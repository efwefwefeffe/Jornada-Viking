# Jornada Viking — 15 Fases

Jogo de plataforma feito com HTML, CSS e JavaScript puro (Canvas 2D), usando os sprites PNG fornecidos.

## Como executar
1. Extraia a pasta `jornada-viking`.
2. Abra `index.html` no navegador (ou use a extensão Live Server no VS Code).

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos e pastas desta pasta para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)` e clique em **Save**.
6. Aguarde alguns minutos e abra o endereço informado pelo GitHub Pages.

## Controles
- A/D ou setas: mover
- Espaço, W ou seta para cima: pular (pulo duplo)
- F: ataque com machado
- R: arremessar machado
- Esc: pausar

Os controles de toque aparecem em telas menores. O Canvas se adapta ao tamanho disponível.
